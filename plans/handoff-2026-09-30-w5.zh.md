### 审批流：graph（编辑态）→ 编译 → wfl 行（运行态）

- `wfl_flow_configs.graph`（json 列）是编辑态唯一事实源；设计器（[`examples/kb-agent/designer/`](../examples/kb-agent/designer/)，React18+antd5+@xyflow/react 12，esbuild 单 bundle）只读写 graph。平台入口「项目与协同 → 审批流配置」iframe 内嵌 `:13110/designer?doc_type=…`（IframeBlockModel；runjs 通道会剥 iframe 标签）。token 鉴权与车间终端同一 `W3_TERMINAL_TOKEN`（URL ?token= → localStorage → x-terminal-token 三通道；dist 的 `<script src>` 无法自举 token，index.html 带内联 loader 注入）。
- 发布链路（[`approval-engine.mts`](../examples/kb-agent/scripts/approval-engine.mts)）：`compileGraphToRows` 经固定词汇表模板+规范角色键派生 wfl 行；门禁（孤立/缺终点/环/审批人空/条件 DSL/引擎可消费矩阵）逐类拒绝；round-trip 等价断言 diff=0 才放行；写入是单条 data-modifying CTE + CAS `graph_version`；发布前行表快照进 config_note（回滚=重放）。10 单据类型已全量迁移（`w5b2 --migrate` 70 断言）。
- 六特性运行态：会签=扇出 k 待办全过聚合、或签任一收敛、依次仅首人待办、回退走 `allowReturn` 边重开待办、抄送 kind=cc 不阻塞、并行节点；`ApprovalAction` 扩 settle/promote/demote/restrict/freeze/eliminate/restore 七业务动作（词汇族终态，`graph.extras.terminals` 声明经编译落行表）。三入口（CLI/HTTP/nb_approve）统一 effect 层——移动端审批同样触发 reserveForSo/MPS 生效钩子；引擎写行 source 固定 'engine'（页面 source='page' 的幻影推进已修）。
- 生效侧自动推进（例外才人工）：IQC passed→自动放行合格区；OQC 放行→自动补欠货 SO 预留；ROP confirm→自动建 PR 草稿回链、ATP 回升自动关 stale 行；SO 发货→自动落 `wms_shipments`。误付可经引擎 void（paid×void）。
- 库存寄存器零残行：`applyStockDelta` 在 delta 落 0 且无占用/锁定时 destroy 该 stock 行（收货按"行缺失即建行"重建）；存量清理 `--sweep-zero-stock`（幂等+对账）。

### UIUX 设计系统（数据承载，平台代码零改动）

- 主题：`themeConfig` uid `mfg-standard`（default）——token 映射 + `token.globalStyle` CSS（九态色板 `--w5-status-*` 变量、表格 tabular-nums）。色板 v2 唯一定义点 [`w5b6-heal.mts`](../examples/kb-agent/scripts/w5b6-heal.mts) `STATUS_PALETTE`（completed/done=cyan 执行完成 ≠ approved 审批绿；文字+颜色双编码）。

## 七、给下一会话的坑清单（W5 全部新增，上轮 12 条继续有效）

1. **runjs JSBlock 剥离 `<iframe>`**——外系统嵌入只能 IframeBlockModel。
2. **`/designer` 无尾斜杠返回 HTML，bundle 引相对路径会按根解析 404**——静态资源一律绝对路径；serve 分发器 `/designer/meta` 必须先于静态前缀分支。
3. **`<script src>` 无法自举 strict token**——index.html 内联 loader 记 URL token 后为 bundle/link 补 `?token=`。
4. **页面回调工作流按 source='page' 重放 /act**——引擎写行 source 必须 'engine'，否则二级审批被幻影推进。
5. **fields:list 双形态**（options 可能是 JSON 字符串；relation 目标在顶层 `target` 列）；**select 字段选项在 `uiSchema.enum`**（collectionFields:list 的 options 恒空）。
6. **迁移默认值保持隐式**——显式写默认 extras 键会破坏探针字节等价（W2-B5「so_orders 无 amount_threshold」）。
7. **psql `-t -A` 下 `DELETE…RETURNING` 输出命令标签**——清理先 SELECT id 再逐行删。
8. **CLI 生效钩子链偶发传输悬挂**——Promise.race 超时 + 幂等 /effective-effects 重放。
9. **时间线/抽屉数据通道**：`init.params.filter` 与 `stepParams.dataScope` 都到不了抽屉首屏——用 PG 视图钉死 doc_type + hasMany(doc_id)。
10. **heal 后再有结构 apply（如 B7 重建抽屉）必须重跑 heal assert**——结构 apply 重搬运旧形态列，色板/对齐声明即刻过期（本轮实证 19 列）。
11. **rolesUsers/rolesResources 族驼峰联表键**（"roleName"，roles 表无 id 主键）。
12. **折叠侧栏文案不是权限探针**——隔离断言用直开 URL+渲染内容对照；CDP 等待文案先实测校准（「SKU」不在库存页 DOM）；localStorage 清后 SPA 可能持内存 token 渲染壳，登录探针需 reload 重试。
13. **W5 证据两个家**：B0~B5 `examples/kb-agent/demos/acceptance-w5/`，B6~B8 仓库根 `demos/acceptance-w5/`。
14. mfg-schedule/mrp-run 类脚本挂 main 守卫后才能被 import（kpi-run 已复用其纯函数；mrp-run 反向 import 会与 top-level await 成环，B4 用子进程 CLI）。
