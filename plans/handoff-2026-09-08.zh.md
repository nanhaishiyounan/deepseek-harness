## 用户业务目标（两工作线的共同北极星）

1. 客户往 agent 上传任何文件，自动路由进知识库或湖仓；agent 回答时自动路由去知识库 / 湖仓 / 连接器数据集取数。
2. 连接器之间的传输必须实现；连接器提供高质量数据集（例：张红喜——漯河电商协会张会长，食品出海尤其中亚方向的行业专家）。
3. 用户问"俄罗斯的仓库被乌克兰炸了怎么办"，agent 能给出应急方案并找到张会长；用户在 agent 里下单后得到张会长的解决方案 PDF（指导货运、仓库等）。
4. （工作线二新增）NocoBase 源码融入本仓库作为企业业务系统主体；数仓 / 知识库从 NocoBase 取数建本体知识图谱；数据资产是公共数据（可查看可下单）；连接器负责交付；所有页面整合进 DSH Web 端；交互 AI 智能化，不要传统填表。
