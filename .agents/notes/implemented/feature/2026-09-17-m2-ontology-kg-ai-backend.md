# Agent Note: M2 backend core — ontology + KG + AI rebuild (P0+P1)

Status: implemented

English | [中文](2026-09-17-m2-ontology-kg-ai-backend.zh.md)

## Problem

The food-KB product's M2 batch promises four capabilities — ontology-driven modeling over five sources, LLM extraction against that ontology, manual graph editing, and natural-language graph edits with rollback. The pre-M2 stack had none of the foundations: registry v4 types carried no constraint quartet or FoodOn anchors, extraction used a free-form prompt with no validation loop, the store had no temporal ledger (no way to answer "which change produced this edge", no rollback), cross-source coreference was deterministic-only with no gray-zone adjudication, and `kg_query` compiled only fixed templates. The batch's [plan](../../../../plans/2026-09-17-kg-mobile-ux/02-m2-ontology-kg-ai-rebuild.md) and [deep research](../../../../research/2026-09-17-ontology-kg-ai-deep-research.md) chose route A (pure-TS in-house enhancement over the existing kg-build/kb-graph/kb-graph-sqlite skeleton, zero Python runtime).

## Decision

**P0 (ontology upgrade + extraction loop).** Registry v5: [`KgPropDef`](../../../../packages/kb/kb-graph/src/types.ts) gains the constraint quartet (`pattern`/`isArray` joining `required`/`enumValues`); `KgNodeType` gains `foodonUri`/`foodonId`/`synonyms`; `KgRelationConstraint` gains per-direction-pair `cardinality {min,max}`; source enum gains `foodon-imported`. FoodOn importer ([foodon-import.ts](../../../../packages/kb/kg-build/src/foodon-import.ts)): curated snapshot (locked 2025-12-30) covering the 张红喜 scenario's four-ring chain, OWL multi-inheritance single-linearized (primary parent along the product facet, secondary parents demoted to `cross-facet` xrefs), subtree roots anchored on builtin classes; kg-build `run()` imports idempotently first and journals an ontology revision for new classes. Instruct-KGC protocol ([extract.ts](../../../../packages/kb/kg-build/src/extract.ts)): schema-dict prompt + split_num batching, but the default stays `legacy` until the A/B gate passes. SHACL validator ([shacl.ts](../../../../packages/kb/kb-graph/src/shacl.ts), internal IR, zero RDF deps) + repair loop ([validate.ts](../../../../packages/kb/kg-build/src/validate.ts)): explanatory feedback with the "re-emit only named items" hard constraint (research-measured 0% vs 63% repair), ≤3 rounds, survivors quarantine — never partial writes. SCHEMA_VERSION 4→5: new `kg_episode`/`kg_mention` (Graphiti-style temporal ledger), `ontology_xref` (SSSOM channel), `kg_align_rejects` (coreference tombstones); `kg_edges.expired_at` (record-level retirement = rollback mark) + `idx_edge_live` partial index; live semantics everywhere = `valid_until IS NULL AND expired_at IS NULL`.

**P1 (temporal + coref v2 + query upgrade).** Store face adds `putEpisode`/`linkMentions`/`listEpisodes`/`edgeMentions`/`edgeIdsOfEpisode`/`expireEdges`/`restoreEdges`/`liveEdgesBetween`/`liveAdjacency`/`putOntologyXrefs`/`putCorefRejects`; episode vs build_run split ledgers (fact-level timing vs pipeline-level audit). `kg_edit` tool ([kg-edit.ts](../../../../packages/kb/tool-kb/src/kg-edit.ts)): propose (NL→closed-set KGCL ops→diff preview) → apply (SHACL precheck, contradiction retirement, episode carries instruction verbatim + diff) → rollback (reverse episode) → episodes; apiproxy gains `kg.episodes`/`kg.rollback` (the kg domain's first write path). corefers_with v2 ([cross-source.ts](../../../../packages/kb/kg-build/src/cross-source.ts)): deterministic floor narrowed to exact matches, containment pairs go to pairwise LLM judgment, ≥0.9 lands, 0.5–0.9 lands flagged for review, negatives tombstone; union-find equivalence classes counted; every pass lands as an ingest episode. `kg_query` L1 (LLM fills template params only) + PPR ([ppr.ts](../../../../packages/kb/kb-graph/src/ppr.ts)) for 2-hop exploration. `runIncremental()` wraps run() with five-system watermark diffing. SourceTrail deep link rides the view-context pending channel into a 2-hop walk with seed selection.

## Consequences

- The v2 deterministic floor must stay exact-match-only: keeping containment matches fills the gray zone with deterministic edges and starves the LLM judge.
- The FakeLlm fixture answers fixed JSON, so instruct-kgc multi-batch calls drop every cross-batch predicate at the closed set (inflated counts) — confirming the default-stays-legacy rule; the A/B evidence lives in [research/2026-09-17-m2-extraction-ab-report.md](../../../../research/2026-09-17-m2-extraction-ab-report.md).
- Unregularized PPR on an undirected graph converges to a degree stationary state: evaluation assertions must use early-iteration locality or degree order, not assume "near > far" survives convergence.
- kg_edit entity resolution orders by planned type first, re-resolves against legal constraint pairs on violation, and lands new entities on constraint-named domains — never inventing types; semantically-right-but-ontologically-illegal instructions refuse with an explanation.
- Full-graph serial pairwise judgment is minutes-to-hours without a verdict cache — a performance follow-up (caching/batched adjudication/incremental gray zones); the verify script pins the v1 alignment leg to stay fast while demos keep v2.
- Verification (2026-09-18 run12, all PASS): four packages' 381 unit tests green; real-API chain ([kg-m2-verify.mts](../../../../examples/kb-agent/scripts/kg-m2-verify.mts), log [m2-verify-real-api-run.log](../../../../examples/kb-agent/demos/m2-verify-real-api-run.log)) covering the v5 rebuild (1137 nodes/788 edges, FoodOn 15 classes, xref=7), SHACL enum-violation interception with a one-round real-LLM repair, the A/B corpus runs, kg_edit end-to-end with rollback, PPR recall ≥ 1-hop baselines, and single-line incremental (one scope updated, 45 others hash-skipped).

## Alternatives considered

- Whole-package Python/Java KG frameworks (Graphiti runtime, Kuzu, full OWL reasoning, free Text2Cypher) — the research's negative list; rejected for runtime weight, hallucination surface, and the existing TS skeleton's fit.
- A full SHACL engine instead of the <200-line internal IR — deferred as the plan's plan-B escape hatch if the minimal validator's coverage falls short.
- Switching the default extraction protocol to instruct-kgc immediately — the A/B gate (dropped-predicate stability) did not pass, so the default stays legacy with the protocol behind config.
- Keeping containment matches in the deterministic coref floor — rejected because it saturates the gray zone (see Consequences).
