# Agent Note：kb 检索相关性阈值 —— RRF 分数标定与默认关闭的论证

Status: implemented

[English](2026-09-02-kb-relevance-threshold.md) | 中文

## Problem

kb 缝（`ctx.kb`）对任意查询都返回 top-N 命中：向量路径无条件返回最近的 `vectorTopK` 个近邻而不管绝对相似度，乱码查询（"qwfpzxcvbnm"、"锟斤拷烫烫烫屯"）因此产出 N 条无关引用，hybrid 部署下工作台的零结果空态在运行时不可达。修复要求在缝上加部署可调的相关性阈值、不改 UI、不伤 eval 基线（hybrid Top5 99%、引用有效率 96%），且分数语义先实测再定。

## Decision

### `minRelevanceScore` 在两种模式下按融合 RRF 分数过滤，默认 0

kb 的 `Config` 新增 `minRelevanceScore`（`z.number().min(0).default(0)`）。`search()` 在结果上限之前丢弃融合分数严格低于阈值的条目；text-only 降级排名改经 `fuseRrf(textIds, [], rrfK)` 计分，使同一阈值在两种模式下含义一致（单路重排精确保持 FTS 排名序——排名倒数分数严格递减）。恰好等于阈值的命中保留（`>=` 语义，由 `1/62` 处的单测锁定）。零结果时 `mode` 不变，工具层的 `truncated` 保持 false（它由 `results.length >= maxResults` 推导）。

### 标定实测了分数范围并发现重合

`examples/kb-agent/scripts/calibrate-relevance.mts`（真实 key、embo-01、k=60、topK 32、eval 语料 + 10 个乱码探针）记录每条融合分数及其路径归属：

- RRF 分数界：单路命中 `(0, 1/(k+1)]` = 0.016393；双路命中 `(0, 2/(k+1)]` = 0.032787。
- 10 个乱码探针全部：全文路径 0 命中、向量路径 32 命中、融合 top-1 恰为 `1/(k+1)`（向量 rank 0 单路）。乱码从不低于单路上限。
- 99/100 的 eval gold 位于 Top5；其中 28 个只走单路（查询匹配不到任何 FTS trigram 短语——表格密集文档碎片化 4 码点窗口），分数 0.014925–0.016393，即**与乱码 top-1 同一区间**。
- 阈值模拟：≤0.015 保持 Top5 99% 但只清空 0/10 个乱码探针；≥0.0164 清空 10/10 个乱码探针但 Top5 降到 71%（恰为双路子集）。

### 默认关闭，因为不存在两全阈值

上述重合是结构性的而非噪声：RRF 分数只是排名的函数，向量单路 rank 0 的命中无论查询是乱码还是正当的表格类问题都同分。任何阈值要么只修剪深排名（乱码 top-1 以 `1/(k+1)` 存活），要么要求双路确认（砍掉 hybrid 相对 text-only 的那 28% 单路召回价值）。因此默认 `0` 上线：既有部署与 eval 基线不受影响（改动后复跑：Top5 99%、引用有效率 98%）。两种部署语义写入 `dsh-kb` README 与 kb-agent DEPLOY：`≤1/(rrfK+1)` = 深排名修剪，`>1/(rrfK+1)` = 双路确认（0.017 清空全部乱码探针；语料相关的单路召回代价并列注明）。

## Alternatives considered

- **默认保守非零阈值（≤0.015）**：否决——标定显示乱码 top-1 存活，买不到空态，却冒语料相关的过度修剪风险。
- **默认双路确认（0.017）**：否决——默默砍掉 28% 单路 gold 召回；eval 语料上 Top5 从 99% 掉到 71%。
- **text 路径门控（FTS 零命中即空结果）**：否决——同样那 28 个正当查询全文零命中；这恰好门控在它们缺失的信号上。
- **按向量余弦相似度设阈值**：能把乱码与那 28 个查询分开的信号是绝对余弦（乱码 top-1 是弱近邻、它们的是强近邻），但 `KbStore.vectorSearch` 不返回分数、`KbSearchHit` 也不携带。把相似度穿透 store 契约是让绝对相关性阈值成为可能的后续工作；为避免同一改动拓宽 store 契约而推迟。

## Consequences

- `packages/kb/kb` 单测覆盖 hybrid 与 text-only 两路阈值过滤、`1/62` 边界的包含/排除、全过滤空结果且 mode 不变、默认关闭回归、负值配置拒绝。
- kb-agent 交付时阈值未设；DEPLOY 记录旋钮、标定方法（`calibrate-relevance.mts`）与双路权衡，运维按语料自决。
- 选择双路确认的部署可达零结果空态；默认部署下空态仅在两路都真正零命中时可达。
- 后续候选如上：经 `KbStore` 契约暴露向量相似度，实现绝对相关性阈值。
