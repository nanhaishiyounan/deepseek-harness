# Agent Note: 视觉模型审查管线——VLM 当发现器，DOM 当裁判

Status: implemented

[English](2026-10-05-w10-vision-audit-pipeline.md) | 中文

## 问题

用户已两次点名界面难看，而 W9/W10 的视觉验收一直是纯人工目测。B1 的回应是不再让用户当第一视觉验收人：把组装态截图喂给视觉模型，用固定的 8 视角提示词让它按严重度/类别/元素级描述枚举缺陷。随后的难题是方法论层面的——VLM 是一台噪声仪器：它会把未滚到底的列表误读为遮挡、把有意的焙线描边叫作原生边框，其原始计数（156 条：11 P0 / 57 P1 / 88 P2）没有验证层就无法当工作清单用。

## 决策

- **管线是 拍摄 → VLM 审查 → DOM 交叉验证 → 按主题批量修复 → 同矩阵复拍 → 复审，以 P0=0 为锚点。** B1 的每条发现由同一活表面的 computed-style 探针打上三选一标签（`confirmed-by-dom` / `visual-only` / `needs-triage`）；只有 confirmed 项驱动修复主题。复审用逐字节相同的提示词跑逐字节相同的矩阵（同路由/同账号/同视口），计数才可比。
- **按跨路由主题修，不逐条修。** B1 的汇总已显示 11 条 P0 中 8 条属「元素未按设计语言重置」：低优先级级联层的 button UA reset（`@layer dshm-button-reset`）、工业蓝清除、暗轨 `--adm-*` 整表映射，三处改动关掉 11 条 P0 外加几十条 P1/P2。动手前先从汇总估主题。
- **复审新报的 P0 要裁决，不盲从。** B3 新报的 3 条 P0 全部被 DOM 证据驳回（list.bottom == tabbar.top 且滚动容器 overflow 滚动 = 未滚到底的误读；画布 #191310 是焙暖黑不是无品牌 #000；Switch 本就走在焙线/柿橙盘上）。每条驳回连同探针数字记进复审报告——锚点「P0=0」指*裁决后*的 P0，不是*未报出*的 P0。
- **剩余 P1 带理由台账**（实测 AA 比值、设计语言内的焙线、§3.2 语义五态色、移动端单行省略惯例）。锚点「P1 ≤ 15」按 B1 的 57 条逐条关键词复发来评估，不用 VLM 每轮的原始计数（「宁可多报」的提示词让它天然浮动）。

## 备选方案

- **对金标集做像素 diff**——否决：缺陷是语义的（UA 残留、对比度、截断策略）不是位移；像素 diff 会被骨架动画与轮询状态淹没。
- **纯人工复审**——否决：那又把用户变回第一验收人，正是本轮要终止的事。
- **顺从模式（VLM 报 P0 就当 bug 盲修）**——否决：复审 3 条「P0」里 2 条是对正确布局的误读；盲修会按模型一句话去重设计一个正确的滚动器和一个合规的开关。

## 后果

- B1→B3 弧线：P0 11→0（裁决后），P1 57→复发 7（其中 1 条本轮修复、6 条带理由台账），needs-triage 27→4（85% 随修复主题自动消失，好于 60% 预估）。DOM 断言（12/12）钉死修复面：抽样 button outset=0、roster 12px→88px、工业蓝 computed 零命中、暗轨胶囊落暗盘、composer 槽 999px。
- 该仪器的已知噪声：跨轮严重度漂移（B1 的 P1 在 B3 复述成 P0）、可滚动列表的遮挡误读、对有意描边的审美升级。三者都由 DOM 裁判 + 台账兜住——所以管线里 VLM 永远只当*发现器*，绝不当*裁判*。
- 可复用脚本在 `demos/acceptance-w10/`（`.shoot-` / `.audit-` / `.dom-verify-`）；下一轮改个前缀、在重建后的网关重跑，构造上就得到可比计数。

## 现场踩坑

- 暗轨此前完全没有 `--adm-*` 声明——暗色下所有 antd-mobile 弹层静默落在亮值或 antd 默认色（胶囊 #f5f5f5）上。经 CSS 变量给组件库换肤时，双轨必须各自整表声明映射；单轨映射是暗色漏洞不是简化。
- antd-mobile 的 TextArea 根本不消费 `--border-radius`（那个拨盘属于 Button）——胶囊纸槽要在包装上加普通 `border-radius`。组件族变量拨盘是按组件划分的；信拨盘名之前先验证消费方。
- `:not([class])` 的 button reset 恰好跳过所有经 CSS module 上脸的 button——reset 必须放进级联层覆盖*全部* button，让无层声明永远靠自身声明获胜。
