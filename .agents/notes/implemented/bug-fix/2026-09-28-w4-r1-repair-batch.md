## Problem

The final verification scored the batch at 70 with two critical findings: (1) the W4 heal's `applyTableDefaultSort` was the third stepParams-clobbering write point — its `stepParams: { resourceSettings: { init } }` payload replaced the whole object (flowModels:save is replace-semantics), wiping `tableSettings` siblings: the four KPI boards lost their `dataScope` board filter (every board showed every board's rows), the reconciliation blocks and the w1 todo table lost their wires; (2) the member (qc_inspector) 质检单 list rendered zero business columns while its data XHR returned full rows — a user-visible regression the journey transcript had papered over.

## Decision

1. **C1 fix is sibling-spread at both levels**: `stepParams: { ...stepParamsBefore, resourceSettings: { ...resourceSettingsBefore, init } }` — the same shape the B6-drill fix gave `assignFormDefaults` and the B2 layout pass. A repo-wide scan of the 89 `flowModels:save` sites found no fourth clobbering write (creation writes are exempt; every update-path write already reads back and merges).
2. **Live-schema restore rides a targeted script, not a replay**: `w4-r1-restore.mts` rewrites the expected `tableSettings` (mirroring `nocobase-w9-dashboards.mts`'s PAGES spec) onto the eight wired w9kpi tables and re-pins the w1 todo `status=open` dataScope (mirroring `ensureTodoJumpLinks`), every write spreading current stepParams first. The w9 `--rollback` full rebuild would have destroyed and recreated pages/charts/collections for a two-key restore; re-running w3-org-acl would have reset unrelated action rows. The wms_lots ledger block needs nothing — its PAGES spec carries no tableSettings.
3. **The member zero-column root cause is the `view` action's field whitelist**: the member role's qm_inspections rows carry `["*","id"]` on view while list/get/create/update carry the full 26-field whitelist. The v2 column renderer's `aclCheck(actionName 'view', fields [name])` matches `"*"` as a literal (platform `TableColumnModel.tsx` → `aclCheck.tsx`: a failed check sets `model.hidden`), so every business column hid while the server honored list/get and returned full rows. Diagnosis eliminated the alternatives live: listMeta identical between roles (26 fields both), the page grid tree byte-identical, `dataSources:listEnabled` identical. The fix aligns the view row's whitelist with list's — one `rolesResourcesActions:update`, no server restart needed, verified through a fresh browser session (17 columns, 14 rows with data).
4. **Point-in-time attribution**: the defect predates B6 — the archived `vfy-b6-09-member-qc-list.png` shows the lone 操作 column at B6 time — and the W4 heal cannot have introduced it (heal writes only the flowModels face; the action rows' updatedAt span 09-27 23:44 through 09-29 01:44 with the heal runs in between leaving list/get/create/update intact). The J4/role-map/journey wording was corrected in place; the journey transcript keeps its history with an appended erratum rather than a rewrite.
5. **Drill transcripts persist atomically with history**: `.b6-regression-drill.mts` had truncated its own 20-line report (including the drill-B stepParams finding) to a 3-line header on the second run. The report now flushes through tmp+rename and prefixes the prior content, so a rerun appends instead of clobbering; the git-recorded 20-line body was restored with the second run's remains kept as an archived tail. `listFlowModels` gained a narrow transport-only GET retry (ECONNRESET/socket hang up) — HTTP errors stay fatal.
6. **Quality-form domain template**: B2's heal now takes per-collection section overrides — qm_inspections splits 检验信息/结果与备注, qm_nc_dispositions 处置信息/结果与备注 — and the document-number placeholders name the domain's real prefixes (如 QI-2026-0001, 来源单号 RCV-…, 如 QM-NC-2026-0001) instead of the generic PO example. The 质检单 code column also gained `sorter: true` (interaction-only; the -id default sort is untouched) — the page previously had no sortable column at all.
7. **Five W4 Agent Notes normalized** to the README format (`# Agent Note:` header, `Status: implemented` line 3, `## Problem` opener, `## Consequences`, `## Alternatives considered`) with zh mirrors and pairing sidecars re-recorded; the format gate now passes 733/733.

## Alternatives considered

- Full w9 `--rollback` rebuild for the dataScope restore — rejected: it destroys pages/charts/collections (and their seeds) to rewrite two stepParams keys a targeted spread-write restores exactly.
- Re-running `nocobase-w3-org-acl.mts` for the whitelist fix — rejected: its touch-through rewrites one row per resource by design and re-running the whole matrix resets unrelated grants the later batches tuned; one aligned `view` write is the minimal surface.
- Attributing the zero-column defect to the W4 heal — rejected on evidence: the archived B6 screenshot already shows it, and the heal never touches rolesResourcesActions; the erratum records the timeline instead.
