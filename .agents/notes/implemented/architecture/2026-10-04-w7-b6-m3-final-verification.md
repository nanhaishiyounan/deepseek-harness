# Agent Note: W7-B6+M3 final verification (114-page sweep, banned-color endgame, W6 zero-regression re-run, mobile dark-track close)

Status: implemented

English | [中文](2026-10-04-w7-b6-m3-final-verification.zh.md)

B6+M3 closes the W7 whole-site aesthetic rework: the mobile dark-track sweep with its contrast fix, and the PC final-verification batch whose job was to re-earn, at one point in time, every claim the earlier batches made.

## Problem

W7's claims lived in per-batch evidence at different points in time; closing the round needed one point-in-time re-earning of every claim, and the mobile dark track had three open legs (the full sweep, the work-detail re-shot, the terminal light-variant tokens).

## Decision

- **Final after set is a fresh full walk, not a collage.** The 114-page census (111 flowPage + 3 v1) re-shot in one run (`.w7b6-shot.mjs after all`, 114/114) into `research/2026-10-03-w7-rework/b6/after/`; the per-batch acceptance PNGs stay where they were and the index (`after-index.md`, generated by `.w7b6-index.mjs`) names all three sources per unit — B6 final, B0 before, and which batch shot it — with per-unit links, no gap tolerance (any MISSING would render bold).
- **The banned-color endcheck sweeps computed styles, not just inline attrs.** The B5 probe read `style=""` attributes; the B6 probe (`.w7b6-probe.mjs`) walks every element's computed `color`/`backgroundColor`/`borderTopColor`/`borderLeftColor` on all 114 pages against the seven-hex ban list, reuses the B5 `probePage` body verbatim for the 23 B5-domain structural assertions (extracted from `.w7b5-shoot.mjs` and run in-page via `new Function`), and probes the three engine-side iframe targets at top level — 13110 is cross-origin to 13000, so the embedded DOM is unreachable from the parent and the same URL at top level is the equivalent visible surface.
- **Antd Badge preset colors are a separate leak class from Tag presets.** The layer-2 `.ant-tag-*` remap never reached `.ant-badge-color-*` (status dots ride `--ant-badge-color`); the sweep caught task-board cyan dots and the fix is one more globalStyle block mapping all badge presets to the same semantic pairs, applied through `w7b0-theme.mts --apply` (layer 2 stays the single entry).
- **JSBlock code deployed by create-only scripts outlives source edits.** The 库位平面图 bin map still rendered the pre-W7 palette because `ensureBinMap` keeps existing blocks; `w7b6-binmap.mts` exports the (now token-referencing) `BIN_MAP_CODE` and redeploys it through `BLOCK_UPDATE_CHANNEL` (`destroy+addBlock` — the stored code rides the server-shaped stepParams.jsSettings, which no direct-update API accepts intact), with the stored code re-read by the B6 probes to assert zero banned hexes.
- **The dark-track selected-Tab state gets its own token.** Measured 2.75:1 (brand `#2a5fa6` on the `#131926` bar) against WCAG 1.4.11's 3:1; lifting the whole brand would break white-on-brand fills, so `--dshm-tab-active` (#5783bc on dark, 4.5:1) splits the state-indicator concern and only the TabBar override consumes it.
- **One matrix script, six legs, honest exit.** `w7-b6-matrix.sh` rolls theme assert + three heal asserts + the 114-page probe + the mobile dark-probe gates into `w7-b6-matrix.log`; the W6 zero-regression legs keep their own scripts (`w6-b10-matrix.sh`, `w6-b10-gates.sh`) and archive into `w7-b6-w6matrix.log` / `w7-b6-w6gates.log`.

## Pitfalls pinned

- **A signed-in SPA ignores localStorage changes until a hard reload** — `goto(same-hash-url)` keeps the in-memory session, so the login surface never mounts; `reload()` after the mutation is the reliable flip.
- **"Click the first button" is not a route.** Work lists lead with an agent-referral card; any detail-capture script must assert the URL pattern and walk on, or read the target id from the store and navigate directly.
- **`page.evaluate` takes one argument.** Passing (fn, a, b) throws Playwright's own "Too many arguments" inside the page — bundle into one object; the four pages that tripped it were probe bugs, not product regressions.
- **Create-only provisioning scripts freeze their deployed output.** Any later source fix needs an explicit update channel (here `BLOCK_UPDATE_CHANNEL` = destroy + `flowSurfaces:addBlock`, then re-read); asserting on the source file alone would have kept the ban list green while the page stayed wrong.
- **Computed-style sweeps see what attribute sweeps cannot.** The bin-map and badge leaks were invisible to the B5 inline-style probe; a final pass owes the stricter instrument.

## Alternatives considered

- **Collage the per-batch PNGs into the final set vs a fresh walk** — a fresh 114-shot run is one script and reflects the verification-time state (post every fix); the collage would have frozen pre-fix renderings into the "final" record.
- **Lift the dark brand globally vs a tab-active token** — global lift breaks white-on-brand button contrast; the split token costs one variable and keeps each surface at its own required ratio.

## Consequences

- The B6 index, probe, and matrix trio are the W7 acceptance baseline any future aesthetic change re-runs; `w7b6-binmap.mts` and the badge globalStyle block extend the layer-2/3b vocabulary for the next JSBlock or preset-color cleanup.
