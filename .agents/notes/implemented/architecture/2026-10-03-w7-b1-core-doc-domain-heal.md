# Agent Note: W7-B1 core-document-domain heal (STATUS_PALETTE v3, column governance, statcard regen) + B0 verifier-debt closure

Status: implemented

English | [中文](2026-10-03-w7-b1-core-doc-domain-heal.zh.md)

B1 is the first stock-page batch under the Forge design language: 22 pages (sales 9 + procurement 8 + CRM 5) healed at the schema layer, plus the seven verifier-debt items the B0 review required before B1 could start.

## Problem

The audit graded the 22 core-document pages as the densest A-grade cluster (legacy palettes, unaligned money columns, ratio-broken statcards), and the B0 review attached seven verifier-debt items before B1 could start.

## Decision

- **STATUS_PALETTE v3** (`examples/kb-agent/scripts/w7b1-heal.mts`, the w5b6 v2 successor): values map to antd preset names that the layer-2 globalStyle renders as the semantic five-state soft pairs; purple is retired (→ Neutral). Semantic deltas vs v2: `started` orange→blue (execution is informational; orange stays for attention states), payment methods demoted to Neutral (leg03: payment channel must not share the status palette), supply-chain grades split (`qualified` green / `preferred` blue, `enhanced` orange / `restricted` red), procurement fulfillment/finance risk colored (`none` 未收货 / `no_invoice` 未开票 orange — leg10: risk states must not render as undifferentiated gray). The full table is documented once in `research/2026-10-03-w7-rework/b0/design-language.md` §2 (the recolor base table B2~B4 inherit); the dry-run lists enum values the table misses so unknowns are extended, not skipped.
- **Walk scope**: `/^(crm_|so_|pur_)/` on the owning collection — the legacy n17 sales ledgers (订单/报价单/回款/发票) live on `crm_*` collections, so CRM masters and sales documents share one matcher without touching hub pages (B2 territory).
- **Option surfaces beyond the field model**: enum option lists live in three places — the DisplayEnumFieldModel under a column, the TableColumnModel's own `props.options` (column-header filter dropdown source), and SelectFieldModel lists under filter/edit forms (which showed English labels). All three are recolored; SelectFieldModel scoping walks the ancestor chain to the nearest `resourceSettings`/`fieldSettings` collection owner because the select row carries none itself.
- **statCardRaw upgraded in `nocobase-flow-page-lib.mts`** (factory = the base for later batches): figure 28/600/#1F2630 with the currency unit at 60% via an ECharts `rich` `{u|}` segment, label 12/500/#55606E, footnote 10/#8A94A0, plus a `/* w7 forge statcard */` marker line. The 46 live w4b3 cards were regenerated by parsing each stored raw (alias from the aggregation read, title/footnote from the JSON text literals, units from the `const text =` concatenation, decimals from `maximumFractionDigits`) and re-emitting through the new factory — heals converge on the marker, so re-running is idempotent.
- **Table density via globalStyle, not per-page props**: thead `padding-block:12px`, cells `14px` block + `12px` inline (≈48-52px rows), and a `1px #EFEFEF` row separator were added to the one theme script's GLOBAL_STYLE and re-applied — B0 stays the single layer-1/2 entry point.
- **B0 debt ①-③** (`w7b0-theme.mts`): apply merges with a standing rollback snapshot instead of overwriting it (a second --apply used to drop `previousDefaultId` to null and degrade rollback to a no-restore; a snapshot already degraded by the pre-fix overwrite self-heals by re-deriving the target from the PREVIOUS_UID row); the user-pinning sweep (themeId outranks the default switch) is part of apply/assert/rollback with a first-seen journal; assert fails on any pinned residue — negative-proven by injecting a stale pin and watching exit=1, then sweeping and watching OK.

## Verification

- `w7b1-heal --assert` OK: 36 enum columns colorMismatch=0, 46 numeric columns right-aligned with separators, 17 date columns formatted, 0 bare-text money/qty columns, 46/46 statcards forge-marked with zero legacy hexes, 29 column-header option lists + 16 form/filter select lists at v3.
- Live DOM probes over all 22 pages (`.w7b1-shot.mjs`): every table page passes thead≥600, header bg ≠white, tag soft (alpha<0.3 or the soft-pair whitelist incl. antd default's `#FAFAFA` neutral), tag pill, numeric cell right+tabular-nums, and no legacy hex inside the v2 surfaces (table + forms; JSBlock interiors belong to B5). Kanban pages pass the tag/geometry probes; calendar pages the hex sweep.
- W6 regression legs: `w6b6-crm --assert` PASS and `w6b7-sourcing --assert` PASS after reseeding the rehearsal rows — the three initial id=0 failures were missing seed data, not heal breakage (heal touches flowModels props/stepParams only, never data rows).
- M0 assertion-③ makeup (`m0/.w7m0-chain.mjs`): login → todos → docs chain green; the approval-flip leg had no live item (empty queue, honestly logged).

## Pitfalls pinned

- **A repeated --apply on an idempotent three-mode script must merge, not rewrite, its rollback snapshot.** The overwrite happened silently because the second run's `previousDefault` was legitimately null (w7-forge already default); rollback then skipped the mfg-standard restore.
- **Enum options live on three distinct nodes** (field model, column row, form SelectFieldModel); healing only the first leaves English labels and pre-W7 colors on filter dropdowns.
- **The DOM tag-soft whitelist must include antd's default-tag neutral `#FAFAFA`** — it is an opaque `rgb(250,250,250)`, alpha 1, yet semantically correct Neutral; asserting on the six soft pairs alone produces false failures on healthy pages.
- **Legacy-hex sweeps must name their surface**: whole-body innerHTML fails on the three pages whose JSBlock embeds hard-coded colors (B5 scope); the v2 assertion runs on `.ant-table` + `form` outerHTML only.
- **Gate scripts that need rehearsal rows degrade to id=0 failures after any cleanup pass** — reseed before asserting, and read the failing items (data-plane) separately from structural checks before blaming the change under test.

## Alternatives considered

- **Recolor via enum options vs globalStyle-only** — options carry the label (中文化) and the semantic mapping; globalStyle alone cannot fix English labels or wrong presets, only their paint.
- **Per-page statcard rewrite vs factory + parse-regen** — one factory upgrade plus a parser over stored raws keeps later batches and the healed cards on the same code path.

## Consequences

- B2~B4 rerun `w7b1-heal.mts` with their domain matchers; unknown enum values surface in dry-run output and extend the same table.
- Rollback for the whole batch is two journals: `b1/w7-b1-heal-rollback.json` (reverse-replayed, `flowModels:save` merge semantics need missing keys written as null) and the theme/user-pin journals under `b0/`.
