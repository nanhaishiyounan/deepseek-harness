# Agent Note: Mobile v6 B2+B3 — the page-form and chat-rich batches on the v6 tokens

Status: implemented

English | [中文](2026-09-23-mobile-v6-uidesign-b2-b3.zh.md)

## Problem

B1 (plans/2026-09-23-mobile-v6-uidesign/01-b1-tokens-shell.md) replaced the token tracks and re-ordered the shell, but every page still rendered the v5 layout on the new colors: home was still the ledger cover leaf, the agents tab still carried a PageNav back header over a flat preset list, the work tab had no tool entries, and the chat surface still used the v4 bubble/composer forms. The design mock's page forms (index (5).html lines 62–308) and its rich-message vocabulary (lines 508–761) had no landing.

## Decision

**B2 — the list pages.** Home re-forms as the mock's 消息 page: the gradient hero greeting (the sanctioned gradient surface), the search-box entry (a visual affordance that lands on `#/chats`, which owns the real filtering), the compact today-ledger chip strip (the four status counts, still routing to work), the quick-task chips, the colleagues' avatar rail (right-edge fade mask), and the recent-chats conv-item rows — 42px stamp avatar with the presence dot, one-line projection preview, relative time, and the unread dot badge off the draftStore watermark (no new state source). The agents tab drops its PageNav (tab pages carry no back header) and renders the capability bands: the colleagues visual table gains optional `group`/`skills`/`status` fields with `rosterBandsOf` grouping (empty bands drop their headings; ungrouped presets collect under 更多 AI 同事) — `agentPreset.list` stays the sole presence source, and the AI presence stays 在线 by product semantics (no fabricated busy states). The work tab gains the 2-column tool grid: one card per roster preset (avatar-colored icon block, duty description, 去聊聊) whose tap rides the real `createSession` + `promptSession` lane with the colleague's first starter as the opener — the mock's `TOOL_SEND` script table never lands. The me tab re-forms onto the me-card (54px gradient avatar), two set-group cards (偏好 / 数据与关于), the 46×27 switch capsules, and the dashed disclaimer note; APP_VERSION reads v6. tasks/files/login already rode the B1 tokens verbatim and needed no edits.

**B3 — the chat surface.** The bubbles take the mock's two states (bot: white bordered plate with the 6px top-left corner; user: the gradient with the top-right corner, both at 78% width, the `msgIn .28s` entrance). The demo typing indicator becomes the breathing three-dot bubble; the day divider drops its pill. The composer re-forms as the input bar: the + entry (brand-soft when the panel is open), the 22px-radius textarea, and the gradient circular send button (disabled at opacity .45); the stop control stays. The slide-up quick panel is hand-rolled (not an antd Sheet): the colleague's own welcome starters (≤6, the welcome card's source) as 2-column commands plus the 语音/文件/表情 placeholder tools that toast 演示版暂未开放 — picking a command closes the panel and sends the starter's send-text through the composer's lane.

**B3 — the rich-message mapping.** Fenced code now leaves the narrative before `sanitizeBizText` (rich.ts `splitCodeBlocks`), so display-term mapping never rewrites an identifier inside a snippet; each fence renders as the deep code plate (track-deepened `--dshm-code-bg`) with its language label and the copy entry (async clipboard → execCommand fallback → toast; copying never touches the session log). The v3/v2 form cards and the report card take the rich-card base (the card2 plate, 13px corners, dashed field rules; inner panels flip to the card face); the decision rows take the three button states (确认写入=pri, 重新编辑=ghost, 驳回=gray); report secondary actions take the ghost fill. The starter/ask picks take the 44px quick-chip capsule (brand on card behind the 35%-brand rim, pressed scale); the ask bubbles lead with the notice glyph on the brand-soft strip. The degraded fence renders the notice form (brand-soft, dashed rim) keeping its human summary text. The work detail's timeline takes the mock's axis form (56px right-aligned time column, the halo dot over the 2px spine, the last row's spine dropped) with `TimelineStep.time` added (live: the tool row's clock; demo: the 01-style ordinal) and a derived progress bar (done/total, the gradient fill, the .8s width transition).

**Explicitly not landed.** The mock's rating stars, its echarts bar chart (the report payload carries discrete metric cards, no per-point series — a bars fallback would render fabricated data), and its per-item todo checkboxes (the three-tier card has no item-check data plane; its phase buttons are the check semantics). The eight fictional colleagues and the FLOWS scripts never enter the code (grep clean).

## Alternatives considered

- Landing the mock's busy/meeting presence mix per preset was rejected: there is no presence source on the wire, and a fabricated busy state would lie about availability; the status chip mechanism stays, every real preset renders 在线.
- Deriving the tool grid from a hand-written TOOLS constant (the mock's eight entries) was rejected in favor of deriving one card per roster preset with the colleague's own starter as the opener — a scripted tool table is exactly the FLOWS-shaped content the plan bans.
- The mock's per-item todo checkboxes and its echarts bar chart had no honest data plane to render (the report payload carries discrete metric cards; the draft card's phases are its check semantics), so both stayed out rather than rendering fabricated state.
- Building the quick panel on antd-mobile's Sheet was passed over for a hand-rolled slide-up: the panel anchors to the input bar inside the chat layer (no tab bar to clear), and the mock's transform timing maps directly onto a keyed CSS animation.

- The quick panel and the deep code plate are new chat surfaces; the aria golden (`chat.expected.md`) was re-recorded and the protocol-invisibility negative assertions stayed green (no fences, no table names, no payload keys).

The rebuilt seed reproduces the recorded golden byte-for-byte in projection.
