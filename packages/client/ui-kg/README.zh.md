# @deepseek-ai/dsh-client-ui-kg

[English](README.md) | 中文

知识图谱页面插件：侧栏一级入口（图谱图标 + 类型数徽标）与 `kg` 会话页签 —— 短语框（把子图查询包装成自然语言：供货链 / 订单 / 含有成分三类模板，其余文本按实体名直接游走）、实体种子搜索（别名解析）、sigma.js v3 画布（graphology + force-atlas2 静态内联进单文件 client.js 产物——浏览器模块表不服务相对路径 chunk；双击展开节点一跳邻居、单击选中）、本体类型图例与按类型过滤画布（颜色骑 ui-theme 的 `--dsw-graph-node-*` 刻度，按类型 id 哈希稳定分配）、实体详情面板（类型 / 关联数 / 业务键）与"问此实体"会话接力。全部数据走连接层的 `api.kg` 面；未启用 `kgEnabled` 的部署内联展示结构化拒绝，无 WebGL 的环境降级为关系清单视图（单击/双击语义不变）。页面只读：图谱写入归 kg-build 管线。

## 模型体验

无：浏览器侧 UI 插件层，渲染网关数据，不注册任何模型可见内容。

#### KV Cache 影响

无：页面在浏览器渲染，不参与任何模型请求；实体提问经输入框草稿接力。

## 已知限制与遗留工作

- 两点路径高亮（graphology 最短路 + 非邻居灰化）随双节点选择交互到来。
- 每次游走跑一次同步 FA2 布局；持续模拟与拖拽钉扎在游走规模常规超过 ~500 节点窗口后到来。
- 画布每次游走整体重绘（既有节点坐标不在新子图间保留）；增量坐标保留随持久布局存储到来。
