# @deepseek-ai/dsh-client-ui-mobile

English | [中文](README.zh.md)

The mobile v8 "AI colleague" client shell: a food-company mobile workspace — a four-tab (消息/同事/工作台/我的) nine-route surface, the AI-colleague chat flow (ticket bubbles + markdown-rich narratives + the v3 fill loop + the v5 report card), and the work loop (report card → create task → isolated execution → source-chat confirmation). Identity is local and login-free (NocoBase 退役后免身份直进): the page keeps a nickname-only identity in localStorage defaulting to「移动访客」, with no token and no login gate; the profile page resets it. The retired NocoBase business surfaces (todos/alerts/docs ledgers, mobile-work sync, relation picking, receipt row read-backs) are gone; the receipt card keeps its static historical rendering, and the kg walks / lakehouse overview / image-describe / extract-text reads stay live. The visual language is the W9「Sauce Amber 酱园琥珀」system (the warm-paper canvas `#fbf5eb`, persimmon `#b4530a` heartbeats, roast-ink text, and the seal grammar — paper-label bubbles, capsule chips, round stamps, ledger-paper receipt cards; the token single source is `demos/acceptance-w9/design-language-w9.md`) plus the W8 accessibility increments. Element-level controls ride antd-mobile v5 widgets over the same `/api` gateway the PC shell uses; sessions and the knowledge graph are shared verbatim.

- **Composition**: `apps/web`'s `mobile.html` entry boots [`AppMobileEntry`](src/client/entry.tsx). A ~70-line unary RPC client ([rpc.ts](src/client/rpc.ts)) speaks the same `/api/<method>` wire as the PC fetch carrier, reduced to the session/agentPreset/llm/kg/lakehouse/data method set. antd-mobile's global base loads at the entry; the `--adm-*` theme maps onto `--dshm-*` declared on both `.dshm-root` and an `html[data-theme]` twin ([tokens.css](src/client/tokens.css)); portals mount into the shell-owned portal host ([portal.ts](src/client/portal.ts)); the root draws the 430px phone shell with the desktop bezel at ≥720px (App.tsx).
- **IA (v6 four-tab, nine routes)**: `#/` (home, the default landing), `#/chats`, `#/chat/:id`, `#/work`, `#/work/:id`, `#/me`, `#/tasks`, `#/files`, `#/agents`; the tab bar's four items are 消息/同事/工作台/我的, chats/chat/work-detail render as full-screen layers, tasks/files as secondary pages ([router.ts](src/client/router.ts) / [MobileShell.tsx](src/client/shell/MobileShell.tsx)). The v1/v2 hashes fold (workbench→work, contacts→agents, messages/data/kg→chats, profile→me); the retired heads (`#/login`, `#/todos`, `#/alerts`, `#/docs`) fall back to home. The four tab pages stay mounted (keep-alive, W8 B1): a lazy first visit mounts the page, `[hidden]` toggles the visible one, and each hidden page suspends its data reads.
- **Chat flow**: each colleague preset owns a session family ([ChatView.tsx](src/client/messages/ChatView.tsx)); the flow folds the durable log into bubbles/tool rows/cards ([fold.ts](src/client/fold.ts)), quick chips fill the composer rather than sending ([QuickPanel.tsx](src/client/messages/chat/QuickPanel.tsx)), fenced actions fire at once, and the offline outbox parks sends for recovery. Freshness comes from polling (1.2s running / 5s idle) with a cancel button over `session.cancel`.
- **Message protocol (v3 + the v5 report fence)**: structured payloads all ride the ```dsh``` fence ([protocol.ts](src/client/protocol.ts): ask_choice/ask_field/form_draft/form_confirm/reject_flow/submit_receipt/report under the `v:3` envelope; broken fences degrade to a collapsed original-text notice). The report card ([ReportCard.tsx](src/client/messages/ReportCard.tsx)) renders the metric grid / entry rows / table / action buttons with the count bounds as part of the contract; four action kinds: view, create-task, send, link. The deterministic widget resolver mirrors `@deepseek-ai/dsh-tool-present-card`'s `src/widget.ts` ([widget.ts](src/client/widget.ts)).
- **Work loop (v5 semantics on the v6 axis form)**: [workStore.ts](src/client/workStore.ts) (localStorage `dsh-mobile-work`) holds four-state work items (待处理→进行中→待确认→已完成, a transition-guarded state machine) — local-only since the mobile-work wire retired; the report card's 创建处理任务 opens the form modal ([actions.ts](src/client/actions.ts)); execution runs in an isolated exec session with the two-mode timeline ([work/workTimeline.ts](src/client/work/workTimeline.ts)); the files page renders 最近文件/AI 生成/收藏, the tasks page splits mine/team.
- **Two modes (live/demo)**: [runMode.ts](src/client/runMode.ts) decides from the profile's explicit AI-preference switch plus an `llm.models` probe; the first-run demo seed ([demoSeed.ts](src/client/demoSeed.ts)) and 清除演示数据 remove exactly the demo items.
- **Fill + human review + submit**: the v3 draft ([forms/v3/DraftCard.tsx](src/client/forms/v3/DraftCard.tsx)) renders the three tiers (需要你定 / 请确认·AI 推导 / 系统生成 folded) with the phase stamp, 确认写入/驳回 on the card, and re-edits riding revision+1; relation fields rest on the opaque `引用 #N` face (the relation read retired with the wire); the receipt is a static metric card that names the retired business system. Card phases replay from the log by draftId+revision ([cardState.ts](src/client/cardState.ts)); the 今天 derived date keeps its client-calendar guarantee ([systemFields.ts](src/client/systemFields.ts)).

The route: served at `/mobile` by the web-app bundle's `mobileEnabled` config (raw `dist/mobile.html`); the PC-side phone-bezel preview lives in `@deepseek-ai/dsh-client-ui-mobile-preview`.

## Model Experience

None, as a browser-side static page the shell renders gateway session/kg/lakehouse/data reads and registers nothing model-facing.

#### KV Cache effect

None: the shell renders in the browser and never contributes to a model request; prompts and tool traffic ride the shared sessions the PC workbench also opens.

## Known Limitations and Deferred Work

- The NocoBase-era identity and business surfaces retired with the source system: the login gate, todos/alerts/docs ledgers, mobile-work sync, relation picking, and receipt row read-backs are gone (empty states name the retirement); identity is a local nickname with no token.
- Work items are local-only (localStorage `dsh-mobile-work`) with no wire sync; restoring sync waits on a carbon-backed account system.
- Relation fields render the opaque `引用 #N` face; a carbon-backed relation read replaces it when the account system lands.
- The receipt card keeps its static historical rendering; it names the retired business system and does not round-trip rows.
