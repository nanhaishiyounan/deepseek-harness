# @deepseek-ai/dsh-client-ui-governance

[English](README.md) | 中文

治理面板界面插件：侧栏导航行（order 12.6）加 `governance` 会话视图四页签 —— 带搜索的跨源资产目录、血缘边列表、可运行评估的质量规则、带 webhook 测试的告警事件。读取走网关的 governance 域（`ctx.governance` 之上）；未组合治理引擎的部署内联展示结构化拒绝。节点半边是空 `apply`，仅为让 Loader 看见插件；浏览器半边经 package.json 的 `dsh.client` 声明由 `./client` 导出装载。

## 模型体验

无：浏览器侧 UI 插件层，渲染网关治理读取，不注册任何模型可见内容。

#### KV Cache 影响

无：面板在浏览器渲染，不参与任何模型请求；治理发现经网关域到达会话，不经本界面。

## 已知限制与遗留工作

- 血缘以边列表渲染；图式血缘可视化（ui-kg 画布做法）随跨源血缘规模增长到来。
- 规则评估由面板按需触发；尚无定时评估面，告警只在手动运行或显式记录后出现。
- 目录页签的搜索是对限定名的大小写不敏感子串；按源或类型的分面筛选随资产目录列注册表到来。
