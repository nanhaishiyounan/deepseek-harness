# @deepseek-ai/dsh-client-ui-connectors

[English](README.md) | 中文

连接器页面板插件：侧栏一级入口（链接图标 + 数据源数量徽标）与 `connectors` 会话页签——带实时可用性的数据源目录（健康圆点与缺凭据态及其行内说明）、按数据源聚合的交付统计（交付次数、行数、最近落库时间）、交付运行时间线（最新在前、带去向标签），以及 AI 辅助的接入引导：以会话接力呈现——预填输入框并切回对话页签（无表单；由助手推荐数据源、补齐参数并测试连接）。全部数据走连接的 `api.connectors` 面；未开启 `connectorsEnabled` 的部署内联展示结构化拒绝，未组合湖仓的部署交付面读作空（即"仅目录"降级）。

## 模型体验

无。作为浏览器侧 UI 插件层，界面渲染网关数据，不注册任何模型可见内容。

#### KV Cache 影响

无：界面在浏览器渲染，从不参与模型请求；接入引导经输入框预填会话草稿。

## 已知限制与遗留

- 连接状态由交付记录推导（每数据源最近一次落库）；Airbyte 式六态健康与流级明细待调度器接管周期同步后引入。
- 运行时间线取网关最新 50 条窗口；历史分页与失败下钻随运行历史 API 一并到来。
- 向导仅做会话接力；页内三页签接入对话框（KbIngestDialog 模式）待连接器可经网关接收凭据后回归。
