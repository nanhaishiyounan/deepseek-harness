# @deepseek-ai/dsh-client-ui-business

[English](README.md) | 中文

业务管理页面插件：侧栏一级入口（账本图标 + 对象数徽标）与 `business` 会话页签 —— 基于 `nocobase.listMeta` 名册的对象切换（隐藏对象已过滤）、问数框（会话接力而非查询框）、对话优先的实体卡流（主标签取 title 类字段、三对纯量预览、每条记录"问此记录/编辑（对话）"与对象级"新建（对话）"接力）、辅助表格视图（`nocobase.list` 的 hasNext 翻页）、NocoBase 嵌入入口 —— 低频管理辅助，经 webserver 按需开启的 `/nocobase` 反代同源呈现。全程无表单：一切写入走会话，由 nb_* 工具承担"预览 → 确认 → 回执"流程。未启用 `nocobaseEnabled` 的部署内联展示结构化拒绝。

## 模型体验

无：浏览器侧 UI 插件层，渲染网关数据，不注册任何模型可见内容。

#### KV Cache 影响

无：页面在浏览器渲染，不参与任何模型请求；记录变更经输入框草稿接力。

## 已知限制与遗留工作

- 卡片流与表格只读前几页（每页 20 行、hasNext"加载更多"）；列筛选与排序控件随表头交互到来。
- 嵌入入口经 `/nocobase` 反代原样呈现业务后台 —— 不做凭据交换，后台保留自身登录；部署发布 embed 页面后，代签链接式嵌入（plugin-embed 页面）随之到来。
- 行级变更通知随 NocoBase workflow 事件通道到来；此前已编辑记录在下一次加载时刷新，非实时。
