# @deepseek-ai/dsh-client-ui-assets

[English](README.md) | 中文

数据资产市场面板插件：侧栏一级入口（市场图标 + 商品数徽标）、`market` 会话页签（板块门户——板块文案、商品/供方/成交计数、来自部署种子文件的典型产品位；可搜索目录与类型筛选；资产详情面板——来源/价格/交付物/专家信息与"问数/引用并提问"的会话接力），以及下单动线——确认卡（只读键值对 + 唯一可编辑的"需求简述"槽位）→ `orders.create` → 带订单号与状态徽标的回执。下单完整复用订单域，本插件不自建写路径。全部数据走连接的 `api.assets` 面（下单另走 `api.orders`）；未开启 `assetsEnabled` 的部署内联展示结构化拒绝。

## 模型体验

无。作为浏览器侧 UI 插件层，界面渲染网关数据，不注册任何模型可见内容。

#### KV Cache 影响

无：界面在浏览器渲染，从不参与模型请求；问数/引用动作经输入框预填会话草稿。

## 已知限制与遗留

- 详情面板呈现发现投影（身份、定价、交付物、专家机构、更新日期）。表格样本行与血缘需要带租户绑定的取数通道，在详情读 API 出现前保持在会话内完成。
- 典型产品位与板块文案来自网关 `assets.stats` 的种子文件；未配置 `assetsSeedPath` 时该栏为空，门户保留 locale 文案。
- 回执徽标展示下单时刻的状态；异步演进（审批 → 已交付）通过会话内的订单工具行可见，此处不做轮询。
- 目录筛选在 `assets.list` 全量结果的客户端完成；服务端分页待目录大到不可整页下发时引入。
