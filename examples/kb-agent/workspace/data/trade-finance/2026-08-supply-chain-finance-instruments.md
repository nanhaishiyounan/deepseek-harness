# 食品产业链常用供应链金融工具对照

## 应收账款类
- 保理：应收账款转让给保理商提前回款，分有追索/无追索；食品行业上游账期 60-90 天常见，保理可压缩到 T+1。
- 电子债权凭证：核心企业确认应付后签发凭证，上游可拆转或贴现，利率通常低于中小企业流贷。

## 存货类
- 存货质押融资：冻品需 -18℃ 监管仓+温度联网监控，质押率常见 50%-60%；原粮质押关注烘干与虫害减值。
- 仓单质押：标准仓单可质押率更高，非标仓单需第三方监管机构背书。

## 预付与订单类
- 订单融资：凭核心企业采购订单融资备货，适合旺季集中备货的休闲食品与调味品企业。
- 买方信贷：为海外买方提供延期付款支持，设备与产线出口适用。

## 选择决策树
1. 账期痛点 → 信保保理/电子凭证；
2. 备货资金痛点 → 订单融资/存货质押；
3. 扩产设备痛点 → 融资租赁；
4. 汇率波动痛点 → 远期结售汇/期权组合。

## 风控红线
- 贸易背景真实性是所有工具的生命线：合同、发票、物流单证、资金流四流合一是底线。
