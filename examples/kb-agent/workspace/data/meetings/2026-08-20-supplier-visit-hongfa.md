# 宏发食品走访纪要（调味品事业部）

- 走访时间：2026-08-20 09:30–15:00
- 走访对象：宏发食品调味品事业部生产总监、采购经理、品控主管
- 记录人：数据归集小组
- 密级：内部资料，企业与个人信息均已脱敏

## 一、企业概况与市场洞察

宏发食品调味品事业部主营酱油、蚝油、复合调味料三条产品线，年产能约 4.2 万吨。采购经理反映：本季度白糖与豆粕采购价格逐月上行，白糖到厂价较年初上涨约 12%，蚝油终端提价空间有限，毛利承压。市场端预制菜配套调味料订单增长明显，事业部计划将复合调味料产能占比从 25% 提升至 35%。

## 二、工艺要点

高盐稀态酱油发酵周期 90–120 天，车间采用日晒夜露工艺。品控主管强调：发酵车间温度控制在 15–30 摄氏度区间，超出区间会显著影响蛋白酶活性。复合调味料炒制工序的受热均匀度是批次稳定性的关键，企业已上线炒制温度在线监测。

## 三、食品安全合规要点（品控主管口述整理）

1. 食品添加剂使用严格执行 GB 2760，复配添加剂按带入原则核算，成品标签须逐一列明。
2. 生产卫生规范执行 GB 14881，微生物监测按生产班次采样，大肠菌群、菌落总数为必检项。
3. 每年一次第三方体系审核（HACCP 为主），客户飞检重点查添加剂台账与留样记录。
4. 标签合规由品控与法务双审，营养成分表检测报告有效期内的检测机构出具。

## 四、成本测算关注点

企业希望平台按"采购到厂价 + 运杂费"口径核算原材料成本；能耗按车间实际产量分摊；白糖行情波动大，希望平台提供月度均价平滑后的成本曲线，辅助定价决策。

## 五、供应链诉求

采购经理提出：希望接入白糖、豆粕、包装玻璃瓶三类原材料的行情数据，形成"行情 → 配方成本 → 定价建议"的联动分析。当前包装材料占成本约 18%，玻璃瓶供应商集中度高，议价能力弱。
