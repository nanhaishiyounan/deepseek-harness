# Ozon/Wildberries 食品类目运营手册（中国卖家版）

## 平台差异
- Ozon：搜索电商为主，重商品卡与评分，佣金结构对食品友好，回款周期约 2 周；
- Wildberries：仓储式（FBO 主导），流量向促销与评论倾斜，超期仓储费高，需要精细的备货节奏。

## 入驻与资质
- 中国法人主体可入驻，需要 EAC 符合性文件与俄语标签实拍；
- 食品类目需通过样品审核：标签、保质期标注、包装完整性。

## 物流选择
- FBP/海外仓：时效最好，适合稳定动销 SKU；
- 直发（中国发货）：测款期用，时效 15-25 天影响转化；
- 头程：铁路拼柜（18-22 天）与公路 TIR（10-14 天）比选，参考平台运价监测数据。

## 定价与促销
- 到手价 = 售价 ×（1-佣金）-物流-仓储-支付费率；促销深度建议控制在 25% 内避免亏损；
- 参加平台大促（如 11.11 俄区）提前 3 周备货入仓。

## 回款与合规
- 回款经第三方支付机构结汇，注意单笔费率与汇率点差；
- 保留 EAC 声明、发票、物流单证备平台抽查。

## 常见坑
- 保质期短于 1/3 剩余期被强制下架；
- 差评集中在物流破损——加强气柱包装。
