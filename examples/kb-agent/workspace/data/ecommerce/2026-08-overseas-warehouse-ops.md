# 食品海外仓运营：库位、效期与滞销治理

## 选仓三要素
- 位置：莫斯科主仓覆盖俄西部，阿拉木图覆盖中亚；多仓分拨要算「头程+二程+仓储」总成本；
- 温区：常温仓为主，巧克力/奶油制品夏季需 18-22℃ 控温仓；
- 系统：WMS 与电商平台 API 对接的成熟度决定库存账实一致。

## 效期管理
- 入库登记生产日期+保质期，系统按「剩余效期/总效期」打标：<1/3 预警、<1/5 禁售；
- 先进先出（FEFO）出库，促销优先推临期批次。

## 库存周转
- 安全库存=日均销×补货周期×1.5；动销率低于类目均值的 60% 触发清仓（组合销售/站外闪购）；
- 季节品（年货、礼盒）按 8 周售罄倒推备货量。

## 滞销与退货
- 退货品仅外包装破损可二次销售（贴新标），内容物破损一律销毁留证；
- 销毁需当地合规渠道并留影像，税务与平台对账都要用。

## 费用结构（示例口径）
- 入库操作费、月仓储费（按托/按 m³）、订单履行费、退仓费四块；旺季（11-12 月）仓储上浮 20%-30%。
