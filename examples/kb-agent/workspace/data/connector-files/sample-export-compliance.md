# 出口合规自查清单（示例投递）

演示文件：把投递目录当作"业务系统外的零散数据"入口，投递后可在「数据资产」市场查看并转入湖仓。

## 中亚市场（哈萨克斯坦 / 乌兹别克斯坦）

- [ ] 标签语言：俄语/哈萨克语双语，配料表按当地译法
- [ ] 认证：EAC 证书覆盖 HS 编码 1905（糕点）、2008（果蔬制品）
- [ ] 保质期承诺：不短于到岸后 60% 货架期
- [ ] 温控记录：冷链段全程 0–4℃，到岸温度记录随车

## 东南亚市场（印尼 / 马来西亚）

- [ ] 清真认证：MUI / JAKIM 认可机构出具，有效期覆盖发运月
- [ ] 标签：印尼语配料表 + 过敏原加粗提示
- [ ] 农残：柠檬酸钠等添加剂符合当地限量，附第三方检测报告

## 通用

- [ ] 商业发票、装箱单、原产地证三单一致
- [ ] 信用证条款与合同付款条件核对（见 trade-finance 语料）
