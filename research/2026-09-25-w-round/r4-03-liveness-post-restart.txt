# R5 补证 — R4 重启后 :3080 进程存活物理证据（2026-09-27）

r4-02 末尾的「重启后存活确认」仅单次 curl 200，缺 PID/lstart 与多次响应的物理链。本文件闭合：
lsof 定位监听进程 → ps 取 lstart → 带时间戳 curl 多次 200，时间戳晚于 lstart。

== 监听 :3080 的进程（lsof） ==

$ lsof -nP -iTCP:3080 -sTCP:LISTEN
COMMAND   PID USER   FD   TYPE             DEVICE SIZE/OFF NODE NAME
node    37891  mac   19u  IPv4 0xf2bf70d00437467e      0t0  TCP 127.0.0.1:3080 (LISTEN)

== 进程 lstart（ps） ==

$ ps -o pid,lstart,command -p 37891
  PID STARTED                      COMMAND
37891 Sun Sep 27 06:55:06 2026     node --import tsx/esm apps/cli/src/bin.ts web --patch examples/kb-agent/cordis.patch.yml --no-open

与 r4-01「重启生效」记录一致：旧进程 8729/8731（Sep 26 9:25PM 起）已 kill；37891 即 R4 重启后的
server 进程（`pnpm dsh web --patch examples/kb-agent/cordis.patch.yml --no-open` 的 node 实体命令），
与旧进程显式区分。

== 带时间戳 curl（时间戳 > lstart 06:55:06 +0800，差约 21 分钟） ==

$ date '+%Y-%m-%d %H:%M:%S %z'
2026-09-27 07:16:45 +0800
$ for i in 1 2 3; do code=$(curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3080/mobile); \
    printf '[%s] /mobile #%d -> %s\n' "$(date '+%Y-%m-%d %H:%M:%S %z')" "$i" "$code"; done
$ for i in 1 2; do code=$(curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3080/); \

PID 37891 即 R4 重启进程且存活服务中：/mobile ×3 与 / ×2 全 200。
